# KBFI Headquarters — Frontend (Vite + React)

This is a production-ready frontend scaffold for KBFI Headquarters built with Vite, React, Tailwind CSS and Framer Motion. It uses local JSON files as a mock API and a modular component architecture.

Getting started:

1. Install dependencies:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes:
- Replace mock JSON data in `src/data/` with real API endpoints and update `src/services/api.js` to use `axios`.
- Add production images and optimize assets.
